だい3わ・その1

ひみつを まもれる おつかいさん

✦ ✦

はいぷ先生きょうは ちょっと おにいさん・おねえさん むけの おはなし。でも だいじょうぶ! 「ひみつを まもれる おつかいさん」と 「ぎんこうの ちょうきびしい ルールブック」の おはなしだよ。

おとなのことば今回のテーマは Confidential Client(機密クライアント)と FAPI2 Security Profile。どちらも OAuth 2.0 のセキュリティに関する用語で、HAIP が求める高保証の土台になっています。
だい3わ・その2

「おつかいさん」って なに?

おつかいさん
ぎんこう

ワレットくんぼくは、あなたの かわりに ぎんこうへ、たいせつな しょうめいしょを とりに いく「おつかいさん」だよ。

ナレーションあなたは おうちで まっているだけ。おつかいさんが かわりに とりに いってくれます。

おとなのことばユーザーの代わりにリソース(ここでは VC)を取りに行くアプリを OAuth では クライアントと呼びます。OID4VCI ではウォレットがクライアントにあたり、発行者(認可サーバー)が「ぎんこう」の役です。
だい3わ・その3

「ほんとうに ほんもの?」

ぎんこうの人

ぎんこうまって まって。きみが 「ほんとうの おつかいさん」だって、どうやって わかるの? もし ニセモノが きたら、たいせつな しょうめいしょを わたせないよ。

おとなのことば認可サーバー(発行者)は「リクエストしてきたクライアントが本物か」を確かめる必要があります。これをクライアント認証といい、なりすまし対策の基本です。
だい3わ・その4

ひみつの あいことば

はいぷ先生そこで、おつかいさんに 「ひみつの あいことば」を もたせるんだ。ぎんこうで あいことばを いえば「あっ、ほんものだ!」って わかる。

ワレットくんでも… その あいことば、どこに しまって おけば いいの? おとしたら たいへんだ!

おとなのことばクライアントが自分の正当性を示す秘密(client secret など)のことです。ポイントは「その秘密を安全に保管できるか」。ここで次の 2 種類に分かれます。
だい3わ・その5

おつかいさんは 2しゅるい

① ポケットしか ない子
② じょうぶな 金庫を もった おみせ

はいぷ先生① ポケットしか ない子は、あいことばを ポケットに いれると おとしたり のぞかれたり しちゃう。

はいぷ先生② じょうぶな 金庫を もった おみせなら、あいことばを 金庫に しっかり しまえる。これが きょうの しゅやく!

おとなのことば秘密を安全に保管できないクライアント=Public Client(公開クライアント)。例:スマホアプリやブラウザ内で動く SPA。秘密を安全に保管できるクライアント=Confidential Client(機密クライアント)。例:サーバー側で動くアプリ。
だい3わ・その6

きみつクライアント = ひみつを まもれる子

✦

はいぷ先生金庫を もった おみせ(きみつクライアント)は、あいことばを 金庫から だして 「ほら、これが しょうこ!」と ちゃんと みせられる。

ぎんこうなるほど! この おみせは しんようできるね。だいじな ものを あんしんして わたせる。

おとなのことばConfidential Client は秘密を安全に保持でき、認可サーバーへ確実にクライアント認証できます。そのぶん信頼度が高く、扱える範囲も広がります。(HAIP の Wallet Attestation は、ウォレットを信頼できるクライアントとして扱うための仕組みです)
だい3わ・その7

でも、あいことば だけでは しんぱい…

ナレーションでも、あつかうのが とっても たいせつな もの(「あなたが だれか」という じょうほう)だと、あいことば だけでは まだ あんしんできません。

ナレーションわる者は、とちゅうで きっぷを ぬすんだり、ニセの ぎんこうを つくったり、あの手この手で だまそうとします。

おとなのことば高保証(High Assurance)の用途では、クライアント認証だけでは不十分です。通信の途中(経路)や、発行されたトークン(きっぷ)の扱いまで含めて、総合的に守る必要があります。
だい3わ・その8

ぎんこうの ちょうきびしい ルールブック = FAPI2

✦ ✦

はいぷ先生そこで とうじょうするのが、「ぎんこうの ちょうきびしい あんぜんルールブック」= FAPI2!

はいぷ先生ぎんこうが お金を まもるくらい きびしい きまりを、ぜんぶ セットに した ものなんだ。

おとなのことばFAPI2 Security Profile = FAPI(Financial-grade API)の第2世代。もともと銀行など金融レベルの高いセキュリティを実現するために作られた、OAuth 2.0 に厳しい規則群を重ねたプロファイル(きまりのセット)です。
だい3わ・その9

FAPI2 の 4つの おやくそく

🚪
こっそり さきに とどけるおねがいを 大声で いわず、ひみつの うらぐちから さきに わたす。PAR
🎫
ペアの わりふだきっぷを とちゅうで ぬすまれても、ペアの あいことばが ないと つかえない。PKCE
🏷️
おくり主の なふだおへんじには かならず「だれが おくったか」の なふだ。ニセぎんこうに だまされない。iss
🔑
かぎつきの きっぷきっぷは かぎを もつ 本人だけ つかえる。ひろっても むだ。DPoP

はいぷ先生この 4つを ぜんぶ まもれば、とちゅうで だまされたり ぬすまれたり しても だいじょうぶ!

おとなのことばFAPI2 が求める主な対策: PAR(RFC9126・認可リクエストの事前登録)/ PKCE S256(RFC7636・コード横取り防止)/ iss による発行者識別(RFC9207・ミックスアップ攻撃対策)/ 送信者制約トークン DPoP(RFC9449・盗んだトークンを使えなくする)。
だい3わ・その10

なぜ こんなに きびしいの?

はいぷ先生なぜ こんなに きびしいの? それは、あつかうのが 「あなたが だれか」という、いちばん たいせつな じょうほうだから。

はいぷ先生だから ぼくの ルールブック(HAIP)は、「この ぎんこうの ルールブック(FAPI2)も まもってね」って いっているんだ。これで VC も ぎんこうなみに あんぜん!

おとなのことばHAIP は「FAPI2 Security Profile の該当条項に準拠する(MUST)」と定めています。VC の発行は「本人性」という最重要情報を扱うため、金融並みの保証が要求されるのです。
